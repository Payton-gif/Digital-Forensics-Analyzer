## Project Description
The Forensic Evidence Analyzer will be a digital forensics tool designed to help investigators organize and analyze digital evidence. The program will scan a selected evidence folder, collect the important information, and organize the evidence chronologically, creating a timeline. 

## Objectives
- Develop a functional digital forensics tool
- Scan and analyze files within an evidence folder
- Collect file metadata and timestamps
- Generate hashes to help verify evidence integrity
- Organize evidence in chronological order
- Generate a readable forensic timeline
- Provide a useful output that can be used during an investigation and in court
- Create a document that explains how this device works

## Scope
In scope:
- Python-based forensic analysis program
- Evidence folder scanning
- File name identification
- File type identification
- File size collection
- Creation of timestamps
- Access timestamps
- Hash generation
- Chronological events timeline
- Ability to search and filter
- Ability to export results
- Final project report 

Out of scope:
- Recovering deleted files 
- Password cracking
- Breaking encyrption
- Network traffic monitoring
- Account investigation
- Mobile device extraction
- Automatic detection of person committing the crime
- Collection of evidence without permits
